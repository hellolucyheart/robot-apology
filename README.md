**The Robot Apology** — a two-line robot confession. Line one owns one
specific mistake: a kitchen robot shelved the cinnamon where the cumin
lives because both jars are the same height, so the curry tasted like
Christmas morning. Line two draws the lesson straight out of that
mistake: matching by size is not matching at all, so now it reads the
label before moving a jar, not after. `main.py` writes the two lines
to `/output/entry.txt`, deterministically, with nothing else in the file.

## Run it

```sh
python3 main.py
```
